{{- /* Override of themes/Stack/layouts/_partials/comments/provider/giscus.html. The only change is the mapping. With mapping="pathname", giscus finds a post's thread through GitHub's discussion search, and when that index goes stale every thread silently disappears and new likes and comments land on empty duplicates (issue #134). Where the deploy step has recorded the post's discussion number in data/discussions.json (export-blog-discussion-urls.sh), load that thread directly with mapping="number". Otherwise, for example on PR previews, which stub discussions.json to {}, fall back to the configured mapping so previews keep their own threads. */ -}} {{- $number := 0 -}} {{- with .Site.Data.discussions -}} {{- $d := index . $.RelPermalink -}} {{- if reflect.IsMap $d -}} {{- $number = int ($d.number | default 0) -}} {{- end -}} {{- end -}} {{- with .Site.Params.comments.giscus -}} {{- end -}}
